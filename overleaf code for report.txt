\chapter*{ABSTRACT}



This study introduces a web tool designed to assess acne severity by ana- lyzing face photos, combining image analysis with machine learning in a practical framework. Its main aim is to give people an easy, quick method to check their skin status at home - without needing instant medical advice. Through patterns found in pictures, the platform delivers early feedback, supporting better tracking and per- sonal decisions about skincare routines. Central to its function is a deep learning model built specifically to detect and rate breakouts accurately.

The model divides skin issues into three types - Clear, Moderate, or Severe depending on spots, swelling, surface shifts, yet other visual signs. The process moves through several steps: gathering data, adjusting images, applying transforma- tions to improve reliability, training the algorithm, also running strict checks for sta- ble results. A specialized server component uses Flask, serving as a bridge between the predictive system instead of the online front end. This REST-based interface manages file submissions, pre-processing tasks, plus delivers forecasts effectively.

For the client side, PHP works together with HTML, CSS, besides JavaScript - to deliver a simple, clear, yet flexible design. Users sign up through the platform, then fill out a brief skin-health form before adding or taking a photo for process- ing. While registration details go into the system, information moves securely via the built-in MySQL setup. This approach keeps personal records protected without compromising consistency across interactions.
The platform shows how machine learning can work well with current web tools to create an easy-to-use acne analysis app. While it’s not meant for medical use, it still offers useful feedback to help people better understand their skin. Its design makes future upgrades possible - like adding broader data or boosting how accurately it sorts skin types offering tailored advice for skin care while also looking into issues such as dark spots, healed wounds, or uneven surface patterns

\chapter{INTRODUCTION}

Acne ranks among the common skin disorders impacting people of various ages. Prompt evaluation of acne severity enables individuals to make choices regarding their skincare and decide if professional medical care is necessary. Nevertheless numerous individuals might lack access to dermatologists or might neglect the importance of timely examination. The increasing prevalence of technology and advancements, in image analysis have enabled the creation of helpful tools that provide preliminary skin evaluations in an easy and user-friendly way. This project investigates a method, via a web-based platform designed to analyze photographs and assess the intensity of acne.

The main objective of this project is to develop an application of determining acne severity through image assessment aided by a machine learning algorithm. A Convolutional Neural Network (CNN) is trained to examine characteristics in facial photos and classify them into categories, like clear moderate or severe. To enable usage beyond the development setting the model is deployed via a Flask API that accepts images analyzes them and delivers predictions. Separating the model from the user interface guarantees operation and allows updates to be made without impacting the frontend. The system’s web application part is built with PHP, HTML, CSS and JavaScript. It offers functionalities like user registration, login filling out a basic skin-health questionnaire and the ability to upload or take facial photos, for evaluation. The questionnaire collects data on routines that might affect skin health allowing the system to provide more tailored advice alongside the prediction. The interface is crafted to be straightforward and flexible enabling users to engage with the system via a browser across devices.
A MySQL database serves to keep user information, login credentials and quiz answers. This guarantees management of user data and enables organized retrieval whenever users engage with the system. The project’s modular design further facilitates maintenance and upgrades. Every part—the database, web interface and machine learning model—can be updated separately allowing adaptability for growth, like adding integrations additional skin conditions or deploying the system on cloud environments.

In general this project illustrates the integration of machine learning methods and web technologies to enhance skincare awareness. Although the system is not designed to substitute medical diagnosis it serves as an initial evaluation tool that assists users in gaining better insight into their skin health. Providing responses based on image analysis and questionnaire data the system promotes well-informed choices and highlights the tangible advantages of technology in enhancing everyday health and wellness activities.

Using deep convolutional networks, they showed high accuracy in diagnosing skin issues - on par with doctors. The system learned from many real-world images, proving capable at spotting irregularities. Because of this, similar models may now support tools designed to detect acne.

2. Automated Acne Severity Grading with CNN Models (2018)

Jones et al. created an early machine-learning system for evaluating acne severity. Instead of standard approaches, they trained CNNs to classify breakouts by seriousness using labeled face photos. Rather than relying on human scoring, their method showed algorithms could achieve better accuracy. This backs up the current project’s approach.

3. Smartphone Based Skin Image Analysis for Dermatology Applications (2020)

What They Did: Back in 2020, Fathy and team checked if regular phone photos work for spotting skin problems. Instead of lab tools, they tested everyday devices on acne and discoloration. After cleaning up the images, results turned out reliable. Because of this, online photo submission became realistic - now a core part of our setup.

4. Deep Learning Frameworks for Acne Severity Classification (2019)

Researchers tested deep learning setups in 2019; they used convolutional layers along with modern feature detection tools to boost acne grading precision. Outcomes indicated a clear edge in detecting acne stages over prior ML approaches. That supports the use of CNN-driven systems in skin assessment.

\section{System overview}
\subsection{Objective}
In this study, we introduce a web tool that detects acne by processing face photos through a trained CNN. Instead of just classifying breakouts into Clear, Moderate, or Severe categories, it combines those outcomes with responses from a skin health survey to deliver tailored tips on avoiding flare ups. Rather than relying on complex setups, the approach focuses on simplicity  offering an easy-to-use online solution designed for everyday individuals checking their skin condition. While maintaining accuracy, the platform emphasizes accessibility so most people can assess concerns without expert help.
\subsection{Scope}
The app supports complete workflows from image capture or upload to preprocessing, then moves to predictions via a Flask API, includes database interaction, secure login, followed by personalized suggestions. It operates across multiple input methods, enabling seamless entry and fast handling. Designed to run directly on everyday devices like laptops, desktops, or smartphones without extra setup.

\section{Low Level Design (LLD)}

Low-Level Design shows how every part inside the Skin Analysis and Acne Detection System actually works. While covering data movement, it also outlines checks that ensure accuracy across processes. Instead of just defining functions, it details steps turning raw input into clear acne severity ratings. Because precision matters, personalized suggestions emerge through structured logic and verified outputs.

\subsection{Process Specification}

Process Specification outlines the inputs, validation steps, internal actions, and outputs of each major process in the system.

% ------------------------------------------------------

\subsubsection{1. User Registration Process}

\textbf{Input:}
\begin{itemize}
    \item Full name, email, username, password
\end{itemize}

\textbf{Validation:}
\begin{itemize}
    \item All fields must be non-empty.
    \item Email must be valid.
    \item Password must meet minimum length.
    \item Email and username must be unique.
\end{itemize}

\textbf{Internal Actions:}
\begin{itemize}
    \item Sanitize input
    \item Check database for duplicates
    \item Hash password using BCRYPT
    \item Insert new user record
\end{itemize}

\textbf{Output:}
\begin{itemize}
    \item Success message or error message
\end{itemize}

% ------------------------------------------------------

\subsubsection{2. Quiz Submission Process}

\textbf{Input:} User quiz responses

\textbf{Validation:}
\begin{itemize}
    \item All required questions must be answered
\end{itemize}

\textbf{Internal Actions:}
\begin{itemize}
    \item Serialize responses to JSON
    \item Store responses in database
\end{itemize}

\textbf{Output:}
\begin{itemize}
    \item quiz\_id for analysis
\end{itemize}

% ------------------------------------------------------

\subsubsection{3. Image Upload \& Forwarding Process}

\textbf{Input:} Image file

\textbf{Validation:}
\begin{itemize}
    \item Accept only JPEG/PNG
    \item Check file size and integrity
\end{itemize}

\textbf{Internal Actions:}
\begin{itemize}
    \item Save temporarily
    \item Forward to Flask prediction API
\end{itemize}

\textbf{Output:}
\begin{itemize}
    \item JSON prediction result
\end{itemize}

% ------------------------------------------------------

\subsubsection{4. Flask Prediction Process}

\textbf{Input:} Multipart image request

\textbf{Validation:}
\begin{itemize}
    \item Confirm image exists
    \item Convert to RGB
\end{itemize}

\textbf{Internal Actions:}
\begin{itemize}
    \item Preprocess image
    \item Run CNN model
    \item Compute prediction and confidence
\end{itemize}

\textbf{Output:}
\begin{itemize}
    \item \{severity, confidence\}
\end{itemize}

% ------------------------------------------------------

\subsubsection{5. Result Presentation \& Recommendation}

\textbf{Input:} Prediction + quiz responses

\textbf{Internal Actions:}
\begin{itemize}
    \item Combine data
    \item Generate personalised recommendations
\end{itemize}

\textbf{Output:}
\begin{itemize}
    \item Result page displaying analysis and advice
\end{itemize}

// User Registration Process\\
FUNCTION RegisterUser(fullname, email, username, password):\\
fullname ← TRIM(fullname)\\
email    ← TRIM(email)\\
username ← TRIM(username)\\
IF fullname = "" OR email = "" OR username = "" OR password = "":\\
RETURN "Error: All fields required"\\
IF NOT VALID\_EMAIL(email):\\
RETURN "Error: Invalid email format"\\
record ← QUERY("SELECT id FROM users WHERE email=? OR username=?", email, username)\\
IF record EXISTS:\\
RETURN "Error: Email or Username already exists"\\
hashed ← HASH(password)\\
status ← EXECUTE("INSERT INTO users(fullname,email,username,password) VALUES(?,?,?,?)", fullname, email, username, hashed)\\
IF status = SUCCESS:\\
RETURN "Registration Successful"\\
ELSE:\\
RETURN "Registration Failed"\\[1em]

// User Login Process\\
FUNCTION LoginUser(loginId, password):\\
loginId ← TRIM(loginId)\\
IF loginId = "" OR password = "":\\
RETURN "Error: Credentials Required"\\
user ← QUERY("SELECT id,password FROM users WHERE email=? OR username=?", loginId, loginId)\\
IF NOT user:\\
RETURN "Error: User Not Found"\\
IF NOT VERIFY(password, user.password):\\
RETURN "Error: Incorrect Password"\\
SET\_SESSION("user\_id", user.id)\\
RETURN "Login Successful"\\[1em]

// Quiz Saving Process\\
FUNCTION SaveQuiz(user\_id, answers):\\
IF user\_id = NULL OR answers EMPTY:\\
RETURN "Error: Missing Quiz Data"\\
jsonData ← JSON\_ENCODE(answers)\\
status ← EXECUTE("INSERT INTO QuizResponse(user\_id,answers\_json,submitted\_at) VALUES(?,?,NOW())", user\_id, jsonData)\\
IF status = SUCCESS:\\
quiz\_id ← LAST\_INSERT\_ID()\\
RETURN quiz\_id\\
ELSE:\\
RETURN "Error: Quiz Save Failed"\\[1em]

// Image Upload and Prediction Process\\
FUNCTION UploadAndPredict(user\_id, quiz\_id, imageFile):\\
IF imageFile NOT PROVIDED:\\
RETURN "Error: No Image"\\
IF imageFile.type NOT IN ["image/jpeg","image/png"]:\\
RETURN "Error: Invalid Image Format"\\
tempPath ← SAVE\_TEMP(imageFile)\\
response ← SEND\_TO\_FLASK("/predict", tempPath)\\
DELETE\_FILE(tempPath)\\
IF response.status != 200:\\
RETURN "Error: Prediction Failed"\\
severity   ← response.severity\\
confidence ← response.confidence\\
IF user\_id NOT NULL:\\
EXECUTE("INSERT INTO AnalysisRecord(user\_id,quiz\_id,severity,confidence,created\_at) VALUES(?,?,?,?,NOW())", user\_id, quiz\_id, severity, confidence)\\
RETURN \{severity, confidence\}\\[1em]

// Flask Prediction Endpoint\\
ROUTE POST /predict:\\
IF "image" NOT IN REQUEST:\\
RETURN ERROR("Image Missing")\\
TRY:\\
img ← OPEN\_IMAGE(request.image).CONVERT("RGB")\\
x   ← PreprocessImage(img)\\
p   ← MODEL.PREDICT(x)\\
idx ← ARGMAX(p)\\
label ← CLASS\_NAMES[idx]\\
conf  ← MAX(p) * 100\\
RETURN \{severity:label, confidence:conf\}\\
CATCH:\\
RETURN ERROR("Processing Failed")\\[1em]

// Image Preprocessing\\
FUNCTION PreprocessImage(image):\\
resized ← RESIZE(image, 224, 224)\\
arr ← NORMALIZE(resized)\\
IF arr HAS 4 CHANNELS:\\
arr ← REMOVE\_ALPHA(arr)\\
arr ← ADD\_BATCH\_DIM(arr)\\
RETURN arr\\[1em]

// Recommendation Generation\\
FUNCTION GenerateRecommendations(severity, answers):\\
recs ← EMPTY\_LIST()\\
IF severity = "Severe":\\
ADD(recs, "Consult a dermatologist")\\
ADD(recs, "Avoid squeezing pimples")\\
ADD(recs, "Use prescribed treatments")\\
IF severity = "Moderate":\\
ADD(recs, "Use gentle cleanser")\\
ADD(recs, "Avoid heavy cosmetics")\\
IF severity = "Clear":\\
ADD(recs, "Maintain routine")\\
ADD(recs, "Use sunscreen")\\
IF answers.water = "low":\\
ADD(recs, "Increase water intake")\\
IF answers.sleep = "low":\\
ADD(recs, "Improve sleep duration")\\
IF answers.stress = "high":\\
ADD(recs, "Reduce stress")\\
RETURN FIRST 5 ITEMS(recs)\\[1em]

// Camera Capture and UI Display\\
FUNCTION CaptureAndSend():\\
stream ← OPEN\_CAMERA()\\
DISPLAY(stream)\\
frame ← CAPTURE\_FRAME()\\
blob ← CONVERT\_TO\_IMAGE(frame)\\
result ← UploadAndPredict(current\_user\_id, current\_quiz\_id, blob)\\
recs ← GenerateRecommendations(result.severity, current\_answers)\\
DISPLAY\_RESULT(result, recs)\\[1em]

// Main System Flow\\
FUNCTION MainFlow():\\
IF NOT LOGGED\_IN():\\
SHOW\_LOGIN()\\
ELSE:\\
SHOW\_DASHBOARD()\\
START\_QUIZ → SHOW\_QUIZ()\\
SUBMIT\_QUIZ → quiz\_id ← SaveQuiz(user\_id, answers)\\
GO\_TO\_CAMERA()\\
CAPTURE\_IMAGE → CaptureAndSend()\\
SHOW\_RESULTS()


\end{flushleft}

// trainmodel.py\\
IMPORT tensorflow AS tf\\
FROM tensorflow.keras.preprocessing.image IMPORT ImageDataGenerator\\
FROM tensorflow.keras.applications IMPORT MobileNetV2\\
FROM tensorflow.keras.layers IMPORT GlobalAveragePooling2D, Dense, Dropout\\

train\_dir = 'split\_dataset/train'\\
validation\_dir = 'split\_dataset/validation'\\
IMG\_HEIGHT = 224\\
IMG\_WIDTH = 224\\
BATCH\_SIZE = 32\\[0.7em]


train\_image\_generator = ImageDataGenerator(rescale=1./255, rotation\_range=40, width\_shift\_range=0.2, height\_shift\_range=0.2, shear\_range=0.2, zoom\_range=0.2, horizontal\_flip=True, fill\_mode='nearest')\\
validation\_image\_generator = ImageDataGenerator(rescale=1./255)\\[0.7em]


train\_data\_gen = train\_image\_generator.flow\_from\_directory(train\_dir, target\_size=(IMG\_HEIGHT, IMG\_WIDTH), batch\_size=BATCH\_SIZE, class\_mode='categorical')\\
val\_data\_gen = validation\_image\_generator.flow\_from\_directory(validation\_dir, target\_size=(IMG\_HEIGHT, IMG\_WIDTH), batch\_size=BATCH\_SIZE, class\_mode='categorical')\\[0.7em]


base\_model = MobileNetV2(input\_shape=(IMG\_HEIGHT, IMG\_WIDTH, 3), include\_top=False, weights='imagenet')\\
base\_model.trainable = False\\[0.7em]


x = base\_model.output\\
x = GlobalAveragePooling2D()(x)\\
x = Dense(1024, activation='relu')(x)\\
x = Dropout(0.5)(x)\\
predictions = Dense(train\_data\_gen.num\_classes, activation='softmax')(x)\\
model = Model(inputs=base\_model.input, outputs=predictions)\\[0.7em]


model.compile(optimizer=Adam(learning\_rate=0.0001), loss='categorical\_crossentropy', metrics=['accuracy'])\\[0.7em]


NUM\_EPOCHS = 20\\

model.save('acne\_detection\_model.h5')\\[1em]

\chapter{CONCLUSION AND LIMITATIONS}

\section{Conclusion}

The Skin Analysis tool uses web tech, machine learning, or image processing to help users check their skin easily. Instead of just one method, it pairs a deep-learning system with questionnaire results - offering early acne evaluation together with custom advice.
The project demonstrates a full workflow - from logging users in, through collecting quiz answers, followed by live photo capture, then analyzing it instantly, finally showing outcomes right away.

\section{Limitations}
Even though it functions properly, some restrictions remain. However, the device
Functionality might fail on outdated browsers or gadgets that lack support
Access settings. Quiz items stay fixed, added by hand - this restricts flexibility
The range of test situations - also, today’s safety steps
for instance, turning passwords into codes is simple but could work better in live systems
use.
The design weighs little; it works well for minor tasks. 


Yet major operations face limits
Deployment could need expanded backend capacity - alongside database tuning - to handle increased demand efficiently
structure.
